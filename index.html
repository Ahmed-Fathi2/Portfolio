CliniKa — AI-Powered Clinical Decision Support Web API

A mission-critical healthcare REST API architected to assist clinicians in diagnosing complex patient cases. It ingests consultation audio, medical documentation, and patient medical history, orchestrating AI workflows (Langflow & Activepieces) to rank top-5 differential diagnoses, recommend confirmatory lab tests, and alert against fatal drug-drug interactions.

Key Engineering Decisions:

  • ⚡ Real-Time SSE Delivery (Zero-CPU Streaming): Replaced HTTP polling loops with Server-Sent Events (SSE) powered by System.Threading.Channels and ConcurrentDictionary. When webhook callbacks return from AI pipelines, ASP.NET Core worker threads are immediately released to the thread pool with zero CPU spinning.
  • 🛡️ Healthcare Security & Verification: Built an automated doctor license verification workflow with administrative approval gates and Twilio SendGrid email activation. Secured clinical endpoints via JWT and fine-grained role claims.
  • 🧪 Automated Testing & CI Pipeline: Structured with 4-Layer Clean Architecture, Repository & Unit of Work patterns, FluentValidation, and a GitHub Actions CI pipeline executing 66 automated xUnit and Moq unit tests on every commit.
